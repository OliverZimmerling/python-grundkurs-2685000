═══════════════════════════════════════════════════════════════════════════════
                    DIE VIER OOP-GRUNDPRINZIPIEN
═══════════════════════════════════════════════════════════════════════════════

  ┌────────────────────────────────────────────────────────────────────────┐
  │  1. KAPSELUNG (Encapsulation)                                          │
  ├────────────────────────────────────────────────────────────────────────┤
  │                                                                        │
  │    private String name;    ← Attribut ist geschützt                   │
  │                                                                        │
  │    public String getName() {   ← Zugriff über Getter                  │
  │        return name;                                                   │
  │    }                                                                  │
  │                                                                        │
  │    public void setName(String name) {   ← Zugriff über Setter        │
  │        this.name = name;                                              │
  │    }                                                                  │
  │                                                                        │
  │  ✓  Daten sind vor direktem Zugriff geschützt                         │
  │  ✓  Kontrolle über Wertänderungen (Validierung möglich)               │
  │  ✓  Interne Implementierung kann geändert werden                      │
  └────────────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────────────┐
  │  2. VERERBUNG (Inheritance)                                            │
  ├────────────────────────────────────────────────────────────────────────┤
  │                                                                        │
  │    public class Student extends Person {                              │
  │        // Student erbt ALLE Eigenschaften von Person                  │
  │    }                                                                  │
  │                                                                        │
  │    IS-A Beziehung:                                                    │
  │    Ein Student IST eine Person                                        │
  │                                                                        │
  │  ✓  Code-Wiederverwendung                                             │
  │  ✓  Hierarchische Klassenstruktur                                     │
  │  ✓  Spezialisierung von Klassen                                       │
  └────────────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────────────┐
  │  3. POLYMORPHISMUS (Polymorphism)                                      │
  ├────────────────────────────────────────────────────────────────────────┤
  │                                                                        │
  │    Person p = new Student(...);  ← Student ist auch eine Person       │
  │    p.begruessung();              ← Ruft Student-Version auf!          │
  │                                                                        │
  │    @Override                     ← Methodenüberschreibung             │
  │    public void begruessung() {                                        │
  │        // Spezielle Begrüßung für Student                             │
  │    }                                                                  │
  │                                                                        │
  │  ✓  Gleicher Methodenname, unterschiedliches Verhalten                │
  │  ✓  Flexibler Code                                                    │
  │  ✓  Dynamisches Binden zur Laufzeit                                   │
  └────────────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────────────┐
  │  4. ABSTRAKTION (Abstraction)                                          │
  ├────────────────────────────────────────────────────────────────────────┤
  │                                                                        │
  │    Klasse = Bauplan (abstrakte Beschreibung)                          │
  │    Objekt = konkrete Instanz                                          │
  │                                                                        │
  │    Person person = new Person("Max", 30);                             │
  │           ▲                   ▲                                       │
  │           │                   │                                       │
  │      Abstrakt           Konkret                                       │
  │                                                                        │
  │  ✓  Komplexität verstecken                                            │
  │  ✓  Nur relevante Details zeigen                                      │
  │  ✓  Implementierungsdetails verbergen                                 │
  └────────────────────────────────────────────────────────────────────────┘

    public String getName() ... ← Überall zugänglich


═══════════════════════════════════════════════════════════════════════════════
              METHODENÜBERSCHREIBUNG (Method Overriding)
═══════════════════════════════════════════════════════════════════════════════

    Person-Klasse:
    ┌─────────────────────────────────────────────┐
    │  public void begruessung() {                │
    │      System.out.println(                    │
    │          "Hallo, mein Name ist " + name);   │
    │  }                                          │
    └─────────────────────────────────────────────┘
                        │
                        │ überschreiben
                        ▼
    Student-Klasse:
    ┌─────────────────────────────────────────────┐
    │  @Override                                  │
    │  public void begruessung() {                │
    │      System.out.println(                    │
    │          "Hallo, ich bin " + getName() +    │
    │          ", Student/in im Studiengang " +   │
    │          studiengang);                      │
    │  }                                          │
    └─────────────────────────────────────────────┘

    Aufruf:
        Person p = new Person("Max", 30);
        p.begruessung();
        ► Ausgabe: "Hallo, mein Name ist Max"

        Student s = new Student("Tom", 22, "123456");
        s.begruessung();
        ► Ausgabe: "Hallo, ich bin Tom, Student/in im Studiengang Informatik"

═══════════════════════════════════════════════════════════════════════════════
                        WICHTIGE SCHLÜSSELWÖRTER
═══════════════════════════════════════════════════════════════════════════════

  this        ► Referenz auf das aktuelle Objekt
              ► this.name = name;

  super       ► Referenz auf die Elternklasse
              ► super.begruessung();
              ► super(name, alter);

  extends     ► Vererbung deklarieren
              ► class Student extends Person

  @Override   ► Annotation für Methodenüberschreibung
              ► Compiler-Prüfung

  new         ► Objekt erstellen
              ► Person p = new Person();
